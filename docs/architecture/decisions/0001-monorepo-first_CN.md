# ADR-0001：前期单仓

[English](0001-monorepo-first.md)

- 状态：已接受
- 日期：2026-08-12

## 背景

当前由一人承担设计、开发、测试和运维。Desktop、gateway 和 engine 的契约在探索期会共同演进。过早拆仓只会增加发版协调，而尚没有独立消费者证明其必要性。

## 决策

三个模块保持在一个仓库，通过明确依赖方向和契约测试隔离。只有独立发版节奏、访问控制或外部 engine 消费者足以抵消成本时才拆分。

## 影响

跨模块改动可以原子提交，CI 集中管理。维护者必须主动阻止直接数据库耦合和越界 import。
