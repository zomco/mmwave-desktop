# ADR-0006：带令牌的临时局域网片段分享

[English](0006-temporary-lan-clip-sharing.md)

- 状态：已接受
- 日期：2026-08-14

## 背景

ADR-0002 规定 TraceCue SPA 和 API 保持回环访问。用户确认一个已生成片段后，还需要让连接同一私有局域网的手机低摩擦地查看、保存和分享这个片段。把主 API 直接开放到局域网会同时暴露设备管理及邻近 NVR 的控制面，超出了这个任务所需的风险范围。

## 决策

主服务继续监听 `127.0.0.1`。只有用户明确点击“手机二维码”后，才在私有网卡上启动独立的临时 HTTP 监听器，并为一个已经校验的本地 MP4 签发 256 位随机能力链接。令牌只保存在内存中，15 分钟后失效，并且只允许通过 `GET`/`HEAD` 访问极简播放页以及该片段的有界 HTTP Range 内容。分享监听器不暴露 TraceCue API、数据库、NVR 地址、凭据或文件系统路径，不记录带令牌的访问日志，并返回严格的浏览器安全响应头。

二维码完全在 SPA 本地生成，不把 URL 发送给云端二维码服务。安装器仍不主动开放防火墙端口；界面会提示用户，首次调用分享时 Windows 可能要求明确允许专用网络访问。

## 影响

令牌是临时持有者凭据：在有效期内，任何获得链接且连接该局域网的人都能查看这个片段。由于临时本地服务没有可用的 HTTPS 身份，传输使用普通 HTTP，因此该功能仅限可信私有局域网和非敏感 beta 验证。完整局域网管理、长期分享、远程中继、撤销界面和 HTTPS 配对仍属于独立安全工作。
