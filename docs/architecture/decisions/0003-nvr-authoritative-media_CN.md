# ADR-0003：NVR 保持为权威媒体存储

[English](0003-nvr-authoritative-media.md)

- 状态：已接受
- 日期：2026-08-12

## 背景

目标现场已经由 NVR 持续录像。第二套录像库会增加存储、转码、可靠性和运维负担，同时削弱低门槛采用路径。

## 决策

只索引元数据 Interval。按通道/时间从 NVR 解析录像，并按需导出短派生 clip；不持续拉取所有录像流。

## 影响

媒体可用性依赖 NVR 保留期和兼容性。录像覆盖、缺口和过期必须显式表达。Clip 缓存是可丢弃派生数据，书签元数据才是持久产品索引。
