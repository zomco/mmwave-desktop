# UX 信息架构

[English](ux-information-architecture.md)

## 主导航（NVR 优先版本）

```text
事件检索
├─ 必填的精确时间、单个可视摄像机和至少一种目标行为
├─ 按 NVR 分组、单选的摄像机截图目标区域选择器
├─ 历史筛选条件
├─ 首次只返回小时密度、事件时长和事件类型构成统计
├─ 用户选择二次统计条件后才分页加载事件预览
├─ 悬停动图及持久的已看/排除状态
└─ 生成候选片段

设备中心
├─ 自动搜索局域网设备
├─ 选择设备并填写凭据
├─ 合并截图、别名与事件通知状态的摄像机卡片
└─ 可切换规则并覆盖栅格/多边形/越界线的只读审计

候选与导出
├─ 浏览器播放与 MP4 下载
└─ NVR 索引事件/片段时间、摄像机和检索来源

设置
└─ 本机夜间开始/结束小时
```

## 仅 NVR 导航

```text
找录像
├─ 日期/时间
├─ 房间/通道
├─ NVR 来源类型/筛选
├─ 候选列表
└─ 片段详情：生成、播放、导出

已导出
设备
诊断与设置
```

页面固定说明候选来自 NVR 录像/事件元数据，可能包含误报。禁止把该视图称为“高置信”或“已降噪”。在 Gateway/Engine 证据成熟前，来源/映射和对照评估不进入主导航。

## 接入 Timeline 后

```text
值得看（默认）
├─ 高置信书签
├─ 质量/来源筛选
└─ 片段详情

全部候选
├─ 高置信时间轴
└─ NVR 原始候选

对照
├─ 审阅量变化
├─ 未匹配/不确定时间段
└─ 时钟健康

来源与映射
已导出
设备
诊断与设置
```

Timeline 过期、来源未映射、质量门控失败或时钟偏差超限时，UI 必须展示降级状态。不得静默回退至 NVR 数据却仍显示高置信标签。
