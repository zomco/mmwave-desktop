# UX 信息架构

[English](ux-information-architecture.md)

## 首次启动

```text
启动 TraceCue
└─ 添加 NVR
   ├─ 地址和凭据
   ├─ 连接及时间检查
   ├─ 能力报告
   ├─ 同步通道
   └─ 房间/通道别名
```

## 仅 NVR 导航

```text
找录像
├─ 日期/时间
├─ 房间/通道
├─ NVR 来源类型/筛选
├─ 候选列表
└─ 片段详情：生成、播放、导出

已导出
设备
诊断与设置
```

页面固定说明候选来自 NVR 录像/事件元数据，可能包含误报。禁止把该视图称为“高置信”或“已降噪”。

## 接入 Timeline 后

```text
值得看（默认）
├─ 高置信书签
├─ 质量/来源筛选
└─ 片段详情

全部候选
├─ 高置信时间轴
└─ NVR 原始候选

对照
├─ 审阅量变化
├─ 未匹配/不确定时间段
└─ 时钟健康

来源与映射
已导出
设备
诊断与设置
```

Timeline 过期、来源未映射、质量门控失败或时钟偏差超限时，UI 必须展示降级状态。不得静默回退至 NVR 数据却仍显示高置信标签。
