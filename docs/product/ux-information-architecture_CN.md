# UX 信息架构

[English](ux-information-architecture.md)

## 主导航（NVR 优先版本）

```text
事件检索
├─ 时间与业务区域
├─ 摄像机和事件类型筛选
├─ 历史筛选条件
├─ 事件预览图库
└─ 生成候选片段

设备中心
├─ 自动搜索局域网设备
├─ 选择设备并填写凭据
├─ 通道与业务别名
└─ 只读事件/规则/通知审计

候选与导出
├─ 浏览器播放与 MP4 下载
└─ 检索、区域、摄像机、事件来源

设置
```

## 仅 NVR 导航

```text
找录像
├─ 日期/时间
├─ 房间/通道
├─ NVR 来源类型/筛选
├─ 候选列表
└─ 片段详情：生成、播放、导出

已导出
设备
诊断与设置
```

页面固定说明候选来自 NVR 录像/事件元数据，可能包含误报。禁止把该视图称为“高置信”或“已降噪”。在 Gateway/Engine 证据成熟前，来源/映射和对照评估不进入主导航。

## 接入 Timeline 后

```text
值得看（默认）
├─ 高置信书签
├─ 质量/来源筛选
└─ 片段详情

全部候选
├─ 高置信时间轴
└─ NVR 原始候选

对照
├─ 审阅量变化
├─ 未匹配/不确定时间段
└─ 时钟健康

来源与映射
已导出
设备
诊断与设置
```

Timeline 过期、来源未映射、质量门控失败或时钟偏差超限时，UI 必须展示降级状态。不得静默回退至 NVR 数据却仍显示高置信标签。
