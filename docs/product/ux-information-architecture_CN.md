# UX 信息架构

[English](ux-information-architecture.md)

## 主导航（NVR 优先版本）

```text
事件检索
├─ 必填的精确时间、单个可视摄像机和恰好一种目标行为
├─ 按 NVR 分组且单选的摄像机截图：可见卡片先加载、已选卡片优先、后台刷新时保留旧缓存
├─ 在所选摄像机画面叠加所选事件类型的实证规则边界
├─ 历史筛选条件
├─ 首次只返回单轨可缩放事件区间时间轴、事件时长和活动模式统计
├─ 点击事件条或拖放子区间，并按该区间动态重算精确时长及孤立/连续触发统计
├─ 用户完成时间轴/全部事件二次选择后才分页加载事件预览
├─ 悬停动图及持久的已看/排除状态
└─ 生成候选片段

设备中心
├─ 自动搜索局域网设备
├─ 选择设备并填写凭据
├─ 合并截图、别名与事件通知状态的摄像机卡片
├─ 可切换规则并覆盖栅格/多边形/越界线的只读审计
└─ 按需显示 NVR/摄像机软硬件详情

候选与导出
├─ 浏览器播放、生成/下载进度与 MP4 下载
├─ 保留目标行为及摄像机/时间主副标题，删除重复来源字段
└─ 为单个就绪片段显式开启 15 分钟、带令牌的局域网二维码分享

设置
└─ 本机夜间开始/结束小时
```

## 仅 NVR 导航

```text
找录像
├─ 日期/时间
├─ 房间/通道
├─ NVR 来源类型/筛选
├─ 候选列表
└─ 片段详情：生成、播放、导出

已导出
设备
诊断与设置
```

页面固定说明候选来自 NVR 录像/事件元数据，可能包含误报。禁止把该视图称为“高置信”或“已降噪”。在 Gateway/Engine 证据成熟前，来源/映射和对照评估不进入主导航。

## 接入 Timeline 后

```text
值得看（默认）
├─ 高置信书签
├─ 质量/来源筛选
└─ 片段详情

全部候选
├─ 高置信时间轴
└─ NVR 原始候选

对照
├─ 审阅量变化
├─ 未匹配/不确定时间段
└─ 时钟健康

来源与映射
已导出
设备
诊断与设置
```

Timeline 过期、来源未映射、质量门控失败或时钟偏差超限时，UI 必须展示降级状态。不得静默回退至 NVR 数据却仍显示高置信标签。
