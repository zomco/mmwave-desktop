# MMWave 家族视觉

[English](visual-language.md)

TraceCue 沿用 MMWave DIY 烧录页的视觉风格，保留产品名、本地优先定位和现有五个导航入口。这是展示层修改，不引入 Home Assistant 或 Fusion 运行时依赖。

`desktop/frontend/src/styles.css` 定义品牌色（主色 `#0b825c`）、浅深色背景、文字、边框和状态语义变量。`ui.tsx` 负责共用按钮、表单、卡片、徽标、标题、焦点状态和线性图标。卡片圆角 16 px、表单 10 px、按钮 8 px；控件高 40–44 px。字体为 DM Sans / Noto Sans SC / 系统字体，不在线下载。正文 14 px，辅助文字至少 12 px，标题 24–30 px、字重 600，数值和技术内容可用等宽字体。

五个页面都使用这些变量。时间轴密度保持绿色，选中区间用琥珀色，拖拽预览用蓝色；摄像机覆盖层保留可区分的分类颜色和细线。视频本身不改色。令牌限定的手机分享页使用相同配色、跟随系统明暗主题；分享权限、有效期、转义和路由不变。

侧栏主题按钮按“跟随系统 → 浅色 → 深色”循环，保存在 `tracecue.theme.v1`；本地存储不可用时仅在当前页面保持选择。减少动画偏好关闭装饰性过渡和旋转动画，不停用状态文字或数据更新。键盘焦点、禁用与危险操作保持可区分。

## 无设备验收

在 `desktop/frontend` 执行 `npm run dev -- --port 5175`，打开 `/test/visual.html`。页面使用真实组件、模拟 API 响应并拒绝所有设备写入。打开 `/test/visual.html?populated#trace` 可检查带模拟录像机的检索表单；摄像机画面故意设为不可用。验收入口参与类型检查，不参与正式构建。检查所有导航页、表单、时间轴、主题切换、键盘焦点和窄/宽屏。执行 `npm test`、`npm run build`、后端分享页测试，并在仓库根目录执行 `python scripts/ci/verify_repo.py`。真实 NVR 播放、HA 原生控件和硬件操作需另行验收。
