# 路线图

[English](roadmap.md)

路线图按能够产生证据的纵向切片组织，而不是按功能数量组织。在首批硬件矩阵形成前，不虚构日期承诺。

软件实现状态与硬件/产品退出证据分开跟踪。截至 0.1.0 开发基线，M1-M5 软件路径已经存在，但下列硬件、发布和人工标注数据退出条件仍未关闭。请查看[实现状态](../development/implementation-status_CN.md)。

## M0——仓库与契约

- 建立产品、架构、安全和 AI 协作基线；
- 建立 `timeline.v1` schema 和示例；
- CI 校验仓库契约和双语文档；
- 退出条件：新协作者不依赖聊天记录即可判断范围、边界和下一项工作。

## M1——海康协议探针

- 只读兼容性探针；
- Digest 认证、设备身份、时钟偏差、通道发现；
- 录像搜索分页和脱敏响应 fixture；
- 媒体解析器证明单通道时间窗能产生 RTSP 输入；
- 退出条件：两组目标 NVR 型号/固件形成有证据的能力报告。

## M2——H.264 出片竖切

- 单 NVR、单通道、单日期范围；
- 持久化作业状态，FFmpeg remux 得到短 MP4；
- 本地浏览器播放，并明确报告录像缺口；
- 退出条件：H.264 金样满足初始播放延迟目标。

## M3——可分发 NVR 基础版

- 局域网发现、多通道/区域/事件筛选、历史筛选、事件预览、规则/通知审计、事件关联导出、H.265/音频兼容路径和诊断包；
- Windows one-folder 安装器、签名流水线和数据保留控制；
- 退出条件：陌生测试者只按书面文档完成安装到播放。

## M4——Timeline 金样路径

- `timeline.v1` 检查/映射/提交；
- 高置信来源与 NVR 来源对照 UI；
- 测量审阅量、精度、召回率和找片耗时；
- 退出条件：人工标注数据支持或否定差异化假设。

## M5——常驻 Gateway

- 对一种认证硬件/型号实现无 HA 雷达采集；
- 时钟健康、短期轨迹缓冲、质量门控和 Interval 持久化；
- Desktop 自动发现/导入；
- 退出条件：Desktop 关闭期间无人值守部署仍能保留正确历史书签。

## 延后事项

局域网开放、流式预览、ONVIF 多品牌、手机直连传输、云中继、自动更新、通道路数授权和硬件套装，均在前置证据成立后再排期。多 NVR 记录已经实现，但跨 NVR 聚合检索仍延后。
