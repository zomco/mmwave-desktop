# Naming status

[中文](naming_CN.md)

- Working English product name: **TraceCue**.
- Chinese product name: **not decided**.
- `Clipmark` is retired because the name is crowded and weak for brand-search ownership.
- “帧索” was discussed as a candidate but has not been adopted.

Preliminary Web search suggested that TraceCue was less crowded than alternatives, but this is not trademark clearance. Before public launch, check at minimum Chinese software/security-related trademark classes, international marks for target markets, domains, GitHub, package registries, Microsoft Store, social/public-account names and relevant company names.

Until clearance is complete:

- Use `TraceCue` in product/document text.
- Use neutral package/application identifiers that can be migrated.
- Do not purchase substantial brand inventory or claim a registered mark.
- Record any rename in an ADR and migration checklist.
