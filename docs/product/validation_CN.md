# 验证方案

[English](validation.md)

## 分开验证不同假设

NVR 基础版验证安装、兼容和出片，不验证高置信差异化。Timeline 阶段才验证信号质量和运营价值。

## 核心指标

| 指标 | 定义 |
| --- | --- |
| 重要事件召回率 | 被书签覆盖的人工标注重要事件 / 全部重要事件 |
| 书签精度 | 实际有人相关的书签 / 全部书签 |
| 审阅量降低率 | 同一时间窗内 `1 - 高置信书签数 / NVR 候选数` |
| 找片耗时 | 从收到房间/日期需求到打开正确片段的时间 |
| 出片成功率 | 可播放 clip / 有效 clip 请求 |
| 首次可播时间 | 请求被接受到浏览器获得首个可播放响应 |

禁止脱离召回率单独汇报审阅量降低。通过漏掉真实事件减少条数不是改进。

## 证据层级

1. 单元/契约 fixture 证明解析和算法；
2. 人工标注金样证明预期事件覆盖；
3. 型号/固件真机测试证明兼容；
4. 陌生用户测试证明可安装和可操作；
5. 试点运营证明重复使用和付费意愿。

开源使用量和 GitHub Star 只是辅助信号，不等于产品市场验证。

## 最小金样数据集

- 完整测试日的 NVR 原始候选；
- 传感器观测和生成的 Interval；
- 包含起止时间、空间和重要级别的人工标签；
- NVR/设备时间观测及人工时钟校正；
- 预期录像覆盖和出片结果；
- 标明算法/配置版本的版本化清单。

客户录像不得进入仓库，只能保存合成或明确获准且已脱敏的 fixture。
