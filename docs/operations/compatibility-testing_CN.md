# 兼容性测试

[English](compatibility-testing.md)

## 先探测，再承诺

首个硬件交付物是只读探针和兼容记录，不是“万能适配器”宣称。只测试所有者控制或明确获授权访问的设备。

## 测试顺序

1. 记录型号、固件、设备时区和测试网络拓扑；
2. 只读探测身份/时间并测量偏差，不修改设备设置；
3. 枚举通道并保存脱敏原始 fixture；
4. 检索一个已知有录像的有界时间窗，包含分页；
5. 使用返回 URI 和/或通道/时间方式解析回放；
6. 运行 FFprobe，尝试 H.264 remux 或文档规定的转码配置；
7. 比较请求与实际 clip 覆盖，并验证浏览器播放；
8. 进程重启后复测，并覆盖无效凭据和录像缺口。

## 证据产物

每项兼容记录包含匿名 fixture 哈希、命令/应用版本、预期能力状态、编码、延迟观测和已知失败。禁止提交凭据或客户图片。

## 支持等级

- **支持：** 在已记录型号/固件上重复通过探测/检索/导出；
- **实验性：** 部分成功或重复次数不足；
- **未知：** 未测试；
- **不支持：** 在有效认证下可复现协议/能力缺失。

单台设备结果不得自动升级整个品牌或系列的支持状态。
