## 已实现产品面

- Engine：值类型、严格的 8 MiB `timeline.v1`、RFC 3339 显式偏移规则、确定性身份、质量门、媒体窗口、合并/过滤和幂等 upsert。
- 海康：Digest HTTP(S)、证据快照、防御性 XML、通道、录像分页、定位符和覆盖缺口。
- Desktop 后端：回环服务、同源安全、SQLite migration v1、DPAPI 引用、HTTP API v1、作业/恢复/取消、书签索引、时间轴映射、片段、配额和有界 Range。
- Desktop 前端：设备添加/探测、检索、诚实标记 NVR 候选、高置信队列、片段播放、时间轴导入/映射、对照和诊断。
- Gateway：无 HA 实验性桥接、时钟健康、有界轨迹缓存、穿越质量、持久 Interval 和导出。
- 交付：精确 npm lock、Python 开发锁、模块 CI、CodeQL、Dependabot、Windows 打包/签名/安装/冒烟和发布 manifest 门禁。

## 仍需外部证据

1. 所有者必须决定仓库/产品许可证并取代 ADR-0004，之后才能发布二进制。
2. 选择可验证的 LGPL FFmpeg/FFprobe 构建，记录来源/版本/哈希和精确声明；若再分发条款允许，只在 Git 历史外放入打包输入。
3. 在两组经授权海康型号/固件上执行兼容性流程，保存脱敏 fixture/证据并测量 H.264/H.265/音频结果。
4. 选择一款完成合法性/协议审查的雷达适配器，采集合成/脱敏 fixture，并执行无人值守时钟/重连/离线保留场景。
5. 执行签名安装包冒烟测试和陌生用户安装到播放测试。
6. 在报告精度、召回率或审阅量改善前，创建或取得获准使用的人工标注数据集。

## 下一个最小可执行步骤

先解决 ADR-0004，然后对第一台所有者控制的海康 NVR 运行只读探针并提交脱敏兼容性证据。该结果将决定媒体与打包硬件门禁能否无需重新设计继续推进。
