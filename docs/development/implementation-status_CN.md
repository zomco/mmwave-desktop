## 已实现产品面

- Engine：值类型、严格的 8 MiB `timeline.v1`、RFC 3339 显式偏移规则、确定性身份、质量门、媒体窗口、合并/过滤和幂等 upsert。
- 海康：Digest HTTP(S)、证据快照、防御性 XML、通道、按需设备详情、普通/Smart 规则覆盖层、历史报警日志分页、录像分页、定位符和覆盖缺口。
- Desktop 后端：回环服务、同源安全、SQLite migration v1-v6、DPAPI 引用、HTTP API v1、有界发现、按摄像机区分普通/Smart 规则能力与覆盖层、有界历史报警日志检索、带最近录像回退且会过期的摄像机识别截图、单摄像机/单事件筛选、带审阅状态和有界事件区间时间轴的持久 Trace 会话、带阶段进度的 JPEG/WebP 预览、严格按事件时间窗的出片作业、用户显式开启且带令牌的临时局域网片段分享、恢复/取消、时间轴映射、配额和有界 Range。
- Desktop 前端：React/Tailwind 事件优先检索、自动/手动设备添加、按需设备详情、合并的摄像机/规则卡片、普通/Smart 分组、按事件能力过滤摄像机、进入页面时刷新一次的按 NVR 分组可视目标选择、所选事件规则覆盖层、去除连续/兜底事件筛选的单一明确行为、单轨可缩放/点击/拖放事件时间轴、动态时长分组、带进度的自动分页预览和悬停动图、事件关联片段播放/生成/下载进度、本地生成的临时分享二维码和本机诊断。时间轴映射/对照已从主导航延后。
- Gateway：无 HA 实验性桥接、时钟健康、有界轨迹缓存、穿越质量、持久 Interval 和导出。
- 交付：精确 npm lock、Python 开发锁、模块 CI、CodeQL、Dependabot、Windows 打包/签名/安装/冒烟和发布 manifest 门禁。

## 仍需外部证据

1. 镜像并审查固定 BtbN 静态 LGPL 依赖集合的完整对应源码和声明；FFmpeg 与构建脚本快照已经固定。
2. 如果需要真正的近实时识别画面，为已授权 `DS-7808NB-K1/8P` 配置具备实时查看权限的专用只读账号；随后在第二组海康型号/固件上重复探针/检索/规则/导出流程。只保存脱敏 fixture/证据并测量 H.264/H.265/音频结果。
3. 选择一款完成合法性/协议审查的雷达适配器，采集合成/脱敏 fixture，并执行无人值守时钟/重连/离线保留场景。
4. 配置获批签名凭据，然后执行签名安装包冒烟测试和陌生用户安装到播放测试。
5. 在报告精度、召回率或审阅量改善前，创建或取得获准使用的人工标注数据集。

## 下一个最小可执行步骤

运行 `packaging/windows/fetch-ffmpeg.ps1 -IncludeSourceSnapshots`，复核生成的构建配置/源码输入，然后对第一台所有者控制的海康 NVR 运行只读探针并提交脱敏兼容性证据。
