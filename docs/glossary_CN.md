# 术语表

[English](glossary.md)

| 术语 | TraceCue 中的含义 |
| --- | --- |
| 书签 | 指向 NVR 媒体的可审阅元数据时间段 |
| Clip | 从 NVR 录像导出的派生短视频文件 |
| Interval | 带来源、通道和可选质量元数据的类型化时间范围 |
| Media window | 解析录像时使用的建议前后缓冲时间窗 |
| NVR 候选 | 来自 NVR 录像/事件元数据的书签；不天然高置信 |
| 高置信时间轴 | 经独立质量门控的 Interval 来源，例如验证后的雷达轨迹 |
| 空间 | 将来源通道连接到一个或多个摄像头视角的业务位置 |
| Recording span | NVR 报告存在录像的时间段，带适配器私有定位符 |
| 能力证据 | 支撑能力状态的型号/固件级观测 |
| Gateway | 常驻来源采集和 Interval 生产者 |
| Engine | 厂商无关 Interval/质量契约库 |
| Lab | 现有 `mmwave-*` 研究仓库；不是产品运行时依赖 |
